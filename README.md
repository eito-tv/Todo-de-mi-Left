# L4D2 Competitive Pack

¡Bienvenido a mi configuración personalizada de Left 4 Dead 2!

Este proyecto reúne los ajustes, comandos y configuraciones que utilizo personalmente para mejorar la experiencia de juego, tanto visualmente como en jugabilidad.

La idea de este pack es sencilla: **llevar tu Left 4 Dead 2 un paso más allá sin complicarte con configuraciones difíciles.**

Aquí encontrarás mi `autoexec.cfg`, con diferentes ajustes de rendimiento, HUD, controles, efectos visuales, Glows, comandos y otras modificaciones que he ido incorporando a mi configuración.

No necesitas ser experto en modding ni saber programar para utilizarlo. La mayoría de los ajustes están preparados para que simplemente descargues el archivo, lo coloques en la carpeta correspondiente y empieces a jugar.

Este proyecto irá actualizándose conforme vaya publicando nuevos videos y configuraciones.

## ¿Qué encontrarás aquí?

* Configuración `autoexec.cfg`
* Ajustes para mejorar la visibilidad
* Configuración de Glows
* HUD y elementos de información
* Bindings y controles personalizados
* Ajustes de rendimiento
* Configuraciones orientadas al juego competitivo
* Diferentes modificaciones y ajustes visuales

**IMPORTANTE:** Esta configuración refleja mis preferencias personales. No significa que todos los valores sean necesariamente los mejores para todos los jugadores. Siéntete libre de modificarla y adaptarla a tu gusto.
